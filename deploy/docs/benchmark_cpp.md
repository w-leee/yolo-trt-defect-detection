# C++ TensorRT FP16 性能测试

## 测试条件
- 硬件: RTX 3050 Laptop (4GB)
- 输入: 416x416, batch=1
- Warmup: 10 次
- 测试: 100 次
- 环境: WSL2 Ubuntu + CUDA 12.6 + TensorRT 10.7

## 结果
| 指标 | 值 |
|---|---|
| 平均延迟 | 4.84 ms |
| 最小延迟 | 3.07 ms |
| 最大延迟 | 13.24 ms |
| FPS | 206.8 |

## 全阶段对比
| 阶段 | 延迟 | FPS | 说明 |
|---|---|---|---|
| PyTorch (Python) | 14.6 ms | 68 | 纯推理 |
| TRT FP16 (Python) | 3.72 ms (P50) | 269 | 纯推理 |
| TRT INT8 (Python) | 3.53 ms (P50) | 221 | 纯推理 |
| **TRT FP16 (C++ 端到端)** | **4.84 ms** | **207** | 预处理+推理+后处理 |

## 结论
- C++ 端到端延迟 4.84ms，**FPS 207**，远超实时检测需求
- 相比 PyTorch 的 14.6ms，加速 3 倍
- 主要瓶颈：OpenCV 预处理（逐像素循环），后续可优化至 2~3ms
